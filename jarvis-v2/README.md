# jarvis-v2 — the HUD

Part of the Agentic OS V2 starter. A Next.js app served on http://127.0.0.1:3217 by `node aos.mjs start` (run from the repository root).

It reads the same vault as the Obsidian plugin, through the local bridge in `../obsidian-v2`, and imports shared code from that folder, so the two folders must stay side by side with these names.

`npm run build` builds it, `npm test` and `npm run typecheck` check it.
